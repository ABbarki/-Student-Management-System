# Student Management System in C — Code Explanation

## 1. Project Overview

This program allows you to:

1. Add a student with a name, ID, and grade.
2. Display all registered students.
3. Search for a student by name.
4. Calculate the average grade of all students.
5. Exit the program.

The program uses **structures, arrays, loops, functions from the C standard library, and conditional statements**.

---

## 2. Include the Libraries

```c
#include <stdio.h>
#include <string.h>
```

### `#include <stdio.h>`

Provides input/output functions:

- `printf()` — displays information.
- `scanf()` — reads formatted input.
- `fgets()` — reads a line of text.

### `#include <string.h>`

Provides functions for working with strings:

- `strcmp()` — compares two strings.
- `strcspn()` — finds the position of a character from a specified set.

## 3. Create the Student Structure

```c
struct Student {
    int id;
    char name[50];
    float grade;
};
```

A `struct` groups related information into one data type.

| Field | Type | Purpose |
|---|---|---|
| `id` | `int` | Student identification number |
| `name` | `char[50]` | Student's name |
| `grade` | `float` | Student's grade |

For example, one student could contain:

```c
id = 1001;
name = "Ahmed";
grade = 15.5;
```

The three fields belong to the same student record.

### Accessing structure members

The dot operator (`.`) accesses a field:

```c
students[0].id
students[0].name
students[0].grade
```

## 4. The `main()` Function

```c
int main(void)
{
    struct Student students[100];
    int count = 0;
    int choice;
```

### `int main(void)`

This is where program execution begins.

### `struct Student students[100];`

Creates an array capable of storing 100 student records.

Each element is a complete `struct Student`.

```c
students[0]  // First student
students[1]  // Second student
students[2]  // Third student
```

Array indexes start at `0`, not `1`.

### `int count = 0;`

Tracks the number of registered students.

Initially, there are no students.

After adding one student:

```c
count++;  // count becomes 1
```

### `int choice;`

Stores the menu option selected by the user.

For example, entering `3` means the user wants to search for a student.

## 5. The `do-while` Loop

```c
do {
    printf("\n===== STUDENT MANAGEMENT SYSTEM =====\n");
    printf("1. Add Student\n");
    printf("2. Display Students\n");
    printf("3. Search Student\n");
    printf("4. Calculate Average\n");
    printf("5. Exit\n");
    printf("Choose an option: ");
```

A `do-while` loop executes its body at least once and repeats while its condition is true.

The menu is displayed every time the loop repeats.

### Read the user's choice

```c
if (scanf("%d", &choice) != 1) {
    printf("Invalid input!\n");
    return 1;
}
```

- `%d` reads an integer.
- `&choice` provides the address where `scanf()` stores the integer.
- `scanf()` returns the number of successfully read items.
- If the input is not a valid integer, the program exits with a nonzero status.

### Consume the newline

```c
getchar();
```

After reading a number, `scanf()` usually leaves the newline generated by Enter in the input stream.

`getchar()` consumes that newline in the expected input sequence.

**Note:** This simple approach assumes ordinary terminal input. More robust programs use a line-reading function to handle invalid input and leftover characters reliably.

## 6. The `switch` Statement

```c
switch (choice) {
    case 1:
        // Add student
        break;

    case 2:
        // Display students
        break;

    case 3:
        // Search student
        break;

    case 4:
        // Calculate average
        break;

    case 5:
        // Exit
        break;

    default:
        printf("Invalid choice!\n");
}
```

The `switch` statement selects a block based on the value of `choice`.

- `case 1` runs when the user enters `1`.
- `case 2` runs when the user enters `2`.
- `default` runs when no case matches.
- `break` exits the switch statement.

Without `break`, execution can continue into subsequent cases.

## 7. Option 1 — Add a Student

### Step 1: Check the array capacity

```c
if (count >= 100) {
    printf("Student list is full!\n");
    break;
}
```

The array can store only 100 students.

If `count` reaches `100`, there is no available array position for another student.

This check prevents writing beyond the array's bounds.

### Step 2: Generate the ID

```c
students[count].id = 1001 + count;
```

The first student receives ID `1001`.

| `count` before adding | Array index | Generated ID |
|---:|---:|---:|
| 0 | 0 | 1001 |
| 1 | 1 | 1002 |
| 2 | 2 | 1003 |
| 3 | 3 | 1004 |

The expression `students[count]` selects the next available record.

### Step 3: Read the name

```c
printf("Enter student name: ");

fgets(students[count].name,
      sizeof(students[count].name), stdin);
```

`fgets()` reads a line from the keyboard.

Its arguments are:

1. Destination array — where the name is stored.
2. Buffer size — the maximum number of characters including the terminating null character.
3. `stdin` — standard input, usually the keyboard.

Unlike `scanf("%s", ...)`, `fgets()` can read names containing spaces, such as `Ahmed Barki`.

### Step 4: Remove the newline

```c
students[count].name[
    strcspn(students[count].name, "\n")
] = '\0';
```

When the user presses Enter, `fgets()` may retain the newline character `'\n'`.

The function `strcspn()` finds the position of the first newline in the string.

For example:

```text
Input: "Ahmed\n"
```

The position of `'\n'` is `5`, so the code replaces it with `'\0'`.

```text
Result: "Ahmed"
```

The null character `'\0'` marks the end of a C string.

If the input contains no newline, `strcspn()` returns the string length, and writing `'\0'` at that position safely terminates the string, provided the input was read into the valid buffer as intended.

### Step 5: Read the grade

```c
printf("Enter student grade: ");

if (scanf("%f", &students[count].grade) != 1) {
    printf("Invalid grade!\n");
    getchar();
    break;
}

getchar();
```

- `%f` reads a `float`.
- `&students[count].grade` gives `scanf()` the address of the grade field.
- The condition checks whether a valid floating-point number was read.

The final `getchar()` consumes the newline after the grade.

### Step 6: Confirm the student was added

```c
printf("Student added successfully!\n");

printf("Student ID: %d\n",
       students[count].id);
```

`%d` displays an integer, so it is appropriate for the student ID.

### Step 7: Increment the count

```c
count++;
break;
```

The increment operator `++` increases `count` by one.

For example:

```c
count = 0;
count++;
```

Now `count` equals `1`.

The next student will be stored in `students[1]`.

**Important limitation:** The grade input error path exits the switch without increasing `count`, which is good, but the partially entered record remains in an unused array slot. The next attempt overwrites it.

## 8. Option 2 — Display All Students

```c
case 2:
    if (count == 0) {
        printf("No students registered yet.\n");
        break;
    }

    for (int i = 0; i < count; i++) {
        printf("\nID: %d | Name: %s | Grade: %.2f\n",
               students[i].id,
               students[i].name,
               students[i].grade);
    }
    break;
```

### Check whether any students exist

```c
if (count == 0)
```

If the number of registered students is zero, the program displays a message and exits this case.

### Loop through the array

```c
for (int i = 0; i < count; i++)
```

The loop starts with `i = 0` and continues while `i < count`.

If `count = 3`, the loop processes indexes `0`, `1`, and `2`.

### Display each record

```c
printf("\nID: %d | Name: %s | Grade: %.2f\n",
       students[i].id,
       students[i].name,
       students[i].grade);
```

Format specifiers:

- `%d` — integer.
- `%s` — string.
- `%.2f` — floating-point number displayed with two digits after the decimal point.

Example:

```text
ID: 1001 | Name: Ahmed | Grade: 15.50
ID: 1002 | Name: Sara | Grade: 17.00
```

## 9. Option 3 — Search for a Student

```c
case 3: {
    char search_name[50];
    int found = 0;
```

The braces create a local scope for variables used in this case.

- `search_name` stores the name entered for searching.
- `found` indicates whether a matching student was located.

Initially, `found = 0` means no match has been found.

### Read the search name

```c
printf("Enter student name: ");

fgets(search_name, sizeof(search_name), stdin);

search_name[
    strcspn(search_name, "\n")
] = '\0';
```

This reads the search term and removes the newline, using the same technique as when adding a student.

### Compare student names

```c
for (int i = 0; i < count; i++) {
    if (strcmp(students[i].name, search_name) == 0) {
```

The loop checks every registered student.

`strcmp()` compares two strings:

```c
strcmp("Ahmed", "Ahmed")  // Returns 0
strcmp("Ahmed", "Sara")   // Returns a nonzero value
```

The condition `== 0` means both strings are equal.

By default, this comparison is case-sensitive, so `"Ahmed"` and `"ahmed"` are different.

### Display the result

```c
printf("\nStudent found!\n");
printf("ID: %d\n", students[i].id);
printf("Name: %s\n", students[i].name);
printf("Grade: %.2f\n", students[i].grade);

found = 1;
break;
```

When a match is found:

1. The program displays the student's information.
2. `found = 1` records the successful search.
3. `break` stops the loop because the student has been found.

### Handle unsuccessful searches

```c
if (!found) {
    printf("Student not found!\n");
}
```

The `!` operator means logical NOT.

Therefore:

```c
!found
```

is true when `found` is `0`.

If the loop finishes without finding the student, the program displays `Student not found!`.

## 10. Option 4 — Calculate the Average

```c
case 4: {
    if (count == 0) {
        printf("No grades available.\n");
        break;
    }

    float sum = 0;

    for (int i = 0; i < count; i++) {
        sum += students[i].grade;
    }

    printf("Average grade: %.2f\n", sum / count);

    break;
}
```

### Step 1: Check for registered students

If `count == 0`, there are no grades to average.

### Step 2: Initialize the sum

```c
float sum = 0;
```

This variable accumulates all the student grades.

### Step 3: Add every grade

```c
sum += students[i].grade;
```

This is shorthand for:

```c
sum = sum + students[i].grade;
```

Suppose the grades are:

```text
12, 15, 18
```

The sum becomes:

```text
sum = 12 + 15 + 18 = 45
```

### Step 4: Divide by the number of students

```c
sum / count
```

The average is:

\[
\text{Average}=\frac{\text{Sum of grades}}{\text{Number of students}}
\]

For the example:

\[
\frac{45}{3}=15
\]

The output is:

```text
Average grade: 15.00
```

## 14. Limitations and Possible Improvements

This is a good beginner project, but keep in mind:

1. **Data is temporary.** Student records disappear when the program exits. File handling can preserve them.
2. **ID generation is basic.** A separate ID counter is safer if you later implement student deletion.
3. **Search is case-sensitive.** Searching for `ahmed` will not find `Ahmed`.
4. **Grade validation is limited.** The program checks that a number was entered, but does not restrict grades to a valid range such as 0–20.
5. **Input handling can improve.** A leftover newline or extra characters can cause problems when the user enters unexpected input.

These improvements can be added as you progress in C.
